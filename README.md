# spbu-deep-learning-course

Домашние задания по курсу глубокого обучения. В репозитории два задания: классификация спутниковых снимков с полуавтоматической разметкой и агрегация оценок асессоров.

| --- | --- | --- |

| №2. Агрегация оценок | `hw2_assessor_aggregation` | [ноутбук](../../blob/hw2_assessor_aggregation/hw2_assessor_aggregation/assessor_aggregation.ipynb) |

Решения лежат в отдельных ветках, отходящих от `main`; после мерджа PR файлы появятся и в `main`. Ссылки выше ведут прямо в ветки.

## Как запустить

Нужен Python 3.10+ и Jupyter. Проверено на Python 3.13 и PyTorch 2.8 (Apple MPS); код также работает на CUDA и CPU.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Каждый ноутбук запускается сверху вниз **из своей папки** (важно для относительного пути к данным).

### ДЗ №1

- Датасет EuroSAT RGB (~94 МБ) скачивается автоматически в `hw1_eurosat_transfer_learning/data/` (папка в `.gitignore`).
- Полный прогон на MPS/GPU занимает около 10 минут; на CPU дольше.
- Предобученные веса ImageNet кэшируются PyTorch автоматически.
- Веса моделей на диск не сохраняются: чекпойнты живут в памяти ноутбука.

### ДЗ №2

- Внешние данные не нужны: датасет генерируется в ноутбуке с фиксированными seed-ами.
- Полный прогон, включая пять симуляций устойчивости, занимает около 10–20 секунд.
- При необходимости можно выгрузить оценки в CSV: `EXPORT_CSV = True` в блоке настроек.

## ДЗ №1. Классификация спутниковых снимков EuroSAT

**Задание преподавателя:**

> Найти и согласовать со мной датасет.
> Обучить как минимум 2 разных архитектуры сетей, использовать разобранные на занятии техники:
> - Итеративная аугментация
> - Итеративная разморозка слоев с адаптивным lr
> - Псевдолейблинг

**Решение.** EuroSAT RGB: 27 000 снимков Sentinel-2, 10 классов. Из них 2 000 размеченных, 19 600 без меток, по 2 700 на валидацию и тест. Сравниваются ResNet-18 и MobileNetV3-Small с весами ImageNet.

- Итеративная аугментация: weak → medium → strong.
- Итеративная разморозка: классификатор → верхний блок (`layer4` / последние три модуля `features`) → вся сеть, с дифференциальным learning rate и `ReduceLROnPlateau`.
- Псевдолейблинг: два раунда, пороги 0.90/0.85, не более 250 снимков на предсказанный класс, вес псевдопотерь 0.4. Ветка с псевдометками сравнивается с контрольной веткой с теми же стартовыми весами и числом шагов.
- Итоговая модель выбирается по `val_loss` **среди всех фаз**, а не по последней фазе.
- Для прироста псевдометок построен парный бутстрэп-интервал.

**Результаты.**

| Модель | Вариант | Test accuracy | Test macro-F1 |
| --- | --- | ---: | ---: |
| ResNet-18 | лучший этап (4) | 93.33% | 93.15% |
| ResNet-18 | контроль | 94.37% | 94.21% |
| ResNet-18 | псевдометки | **94.59%** | **94.42%** |
| MobileNetV3-Small | лучший этап (2) | 88.37% | 87.99% |
| MobileNetV3-Small | контроль | 88.37% | 87.99% |
| MobileNetV3-Small | псевдометки | 88.37% | 87.99% |

- ResNet-18 последовательно выигрывает от разморозки: 85,04% → 87,11% → 91,93% → 93,33% по этапам.
- Полная разморозка MobileNetV3-Small ухудшила качество (88,37% → 84,37%), поэтому выбран чекпойнт второго этапа.
- Псевдометки: точность 99,9% у ResNet-18 и 99,4–99,7% у MobileNet, покрытие 12,8% пула. Прирост ResNet-18 — +0,22 п.п. accuracy с 95%-м интервалом [-0,33; +0,74], то есть статистически неотличим от нуля.


## ДЗ №2. Агрегация оценок асессоров

**Задание преподавателя:**

> Сгенерировать или найти датасет асессорских оценок, посчитать по нему разные статистики и описать почему они похожи на реальные данные.
> Применить методы агрегации:
> - Majority Vote
> - Weighted Majority Vote
> - (после след занятия) Dawid Skene
> Замерить качество, сделать выводы.

**Решение.** Сгенерированы 2 000 заданий и 40 асессоров; 400 заданий — gold-калибровка, 1 600 — тест. На задание 3–7 оценок. Модель генерации имитирует реальную краудразметку: разный опыт и загрузку исполнителей, сложность заданий, асимметричные ошибки между классами и личные склонности асессоров.

- Статистики: перекрытие, нагрузка, согласие, единогласие/ничьи, согласие по сложности, Krippendorff's alpha, распределение классов, точность на калибровке.
- Majority Vote и Weighted Majority Vote (сглаженные веса по gold-калибровке) сравниваются с Dawid–Skene, который использует все оценки, но не использует gold.
- Качество: accuracy, macro-F1, accuracy по сложности, confusion matrices, парные бутстрэп-интервалы.
- Устойчивость проверена на пяти независимых симуляциях; гиперпараметры фиксированы заранее.

**Результаты (seed 42).**

| Метод | Accuracy | Macro-F1 | Δ accuracy vs MV |
| --- | ---: | ---: | :--- |
| Majority Vote | 73.69% | 73.91% | — |
| Weighted Majority Vote | 74.62% | 74.98% | +0.94 п.п. [−0.31; +2.25] |
| Dawid–Skene | 76.00% | 76.37% | +2.31 п.п. [+0.44; +4.06] |

Dawid–Skene выигрывает на всех пяти симуляциях (в среднем 78.46% против 76.83% у Weighted MV и 74.72% у MV). Согласие низкое (Krippendorff's α = 0.203), у отдельного ответа accuracy 60.7%, у Majority Vote — 73.7%: агрегация даёт около +13 п.п.
